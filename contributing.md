# Contributing Guide

Welcome to the workshop! Follow these simple steps to fix the buggy code and submit your first Pull Request (PR).

## Step 1: Fork and Clone
1. Click the **Fork** button at the top right of this repository to create your own copy.
2. Clone your forked repository to your local machine:
   ```bash
   git clone https://github.com/YOUR-USERNAME/gitgud_lab3.git
   cd gitgud_lab3
   ```

## Step 2: Solve the Problem
1. Check the `questions/` folder for the buggy C++ files. Pick a problem you want to solve.
2. Go to the `solutions/` folder.
3. **Important:** Create a new folder inside `solutions/` with your exact GitHub username. 
   *(Example: `solutions/johndoe/`)*
4. Write your corrected C++ code inside your personal folder. 

*Note: Doing this ensures everyone can merge their PRs without conflicts!*

## Step 3: Commit and Push
Once your solution is ready, save the file and run these commands in your terminal:

```bash
git add .
git commit -m "Added solution by YOUR-USERNAME"
git push origin main
```

## Step 4: Create a Pull Request (PR)
1. Go to your forked repository on GitHub.
2. Click the **Compare & pull request** button.
3. Add a short title and description (e.g., "Fixed calci.cpp").
4. Click **Create pull request**.

That's it! You have successfully submitted your contribution. We will review and merge it soon.
